# SDK의 Windows Tauri 호스트 선택

2026-11-20 · 구현·검증 완료 · 원문: `work2.md` (`git show 1c51f17d:work2.md`)

- **구현:** 설치된 CLI의 `--target windows --host tauri` 경로로 준비·진단·개발·빌드·실행을 제공했다. Rust 템플릿과 잠금 파일·권한·아이콘을 공급하고, 앱별 빌드 잠금과 실패 시 이전 EXE 보존을 적용했다. 외부 기본 스타터의 애니메이션 수명 오류도 수정했다.
- **검증:** Demo, Testbed, 저장소 밖 한글·공백 경로의 새 앱에서 단독 EXE의 WebGL2·IPC를 확인했다. 두 샘플의 내장 자산 해시, 동시 개발 창의 독립 HMR·포트 정리, 기존 Chrome·Windows 기본 호스트 실행도 확인했다.
- **해석:** 사용자는 네이티브 경로보다 부드럽고 120Hz에 가깝다고 느꼈다. 주사율이나 표시 FPS를 측정한 결과는 아니다.
