# 텍스트 선택 메뉴와 글줄 확대경

2026-11-22 · CLOSED / PARTIAL · 원문: `work6.md` (`git show 1c51f17d:work6.md`)

- **구현:** Material·Cupertino 편집기와 읽기 전용 선택 표면에 우클릭·길게 누르기 메뉴, 선택 범위 보존, 글줄 좌표 기반 확대경을 연결했다. SDK에서 브라우저와 Tauri의 메뉴 소유권을 나누고, 비동기 클립보드 명령이 늦게 끝날 때 선택·포커스를 다시 확인한다.
- **확인:** Pixel 5에서 길게 누르는 동안 확대 글자 픽셀을 확인했고, 손을 떼면 선택을 유지한 채 메뉴가 열렸다. 터치 취소, OS 클립보드, WebGL 복구 후 재선택이 통과했다. Chrome은 권한 거절·늦은 Paste 폐기를, Windows 패키지는 우클릭과 OS 클립보드 왕복을 확인했다.
- **한계:** Chrome 읽기 전용 Material에서 전체 선택 후 다시 우클릭하면 Copy가 사라졌다. Windows 키보드 메뉴와 전체 선택도 통과하지 못했다. W5 대비 스크롤은 표본·도착 카드가 달라 회귀를 판정하지 않았다. 미완료 인수는 [W7](work7-summary.md)로 이관했다.
