# @nelyx/material

Material 3 only. Material 2 is excluded from this package and future W14 work. `ThemeData.useMaterial3`, its constructor/copy option, M2 elevation overlay options/methods, `ChipThemeData.fromDefaults` and `SliderThemeData.fromPrimaryColors` have been removed. Invalid legacy theme options throw at the JavaScript ingress. Current and 2023 M3 slider/progress variants remain supported; the upstream 2023 M3 range defaults share older geometry. Explicit custom colors, shapes, zero-thickness hairlines and ink factories remain usable.

Selected material widgets on a single @nelyx/core 0.16.0 instance. Import directly from `@nelyx/material/widgets`. This package owns its implementation and notices; it does not claim the complete Flutter design library. The common AppTheme/AppThemeData in core remains an Nelyx host adapter, not Flutter's canonical design theme.

Source imports use public core subpaths; emitted modules and declarations require no Dart, generator or scratch files.

`filled-button`, `text-button`, `outlined-button`, `elevated-button` and `widgets` share `FilledButton`, `TextButton`, `OutlinedButton`, `ElevatedButton` and `FilledButton.tonal`. Options accept a Widget child, nullable press/long-press callbacks, external focus/state controllers and selected `ButtonStyle` fields; the existing FilledButton `(id, label, onPressed)` constructor is retained. Widget properties precede the nearest button theme, ThemeData button theme and pinned M3 color defaults. Source WidgetStateProperty color resolution consumes actual disabled/pressed/hovered/focused states. Style fields currently cover foreground/background/overlay color, text style, padding, minimum size and a uniform `radius`; the radius property uses an explicit DartDouble carrier/witness at the generic boundary. Theme data constructors use `{style}`. Arbitrary shapes, elevation/shadows, full ink effects and icon variants remain incomplete.

`checkbox`, `radio`, `switch` and `widgets` export controlled `Checkbox`, `Radio<T>` and `Switch`. The parent retains each value; input requests a change through callbacks. Shared Core owns focus/actions, gesture cancellation, state properties, semantics, ticker policy and retirement. The feature sections below describe the current source API and painter coverage. Haptic delivery and complete native/reader qualification remain separate work.
